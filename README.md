# 套版比對台 · 多檔 PDF 差異檢查

**👉 直接開啟使用:https://larry9630.github.io/pdf-compare/**

在瀏覽器裡並排比對多份 PDF、疊圖找差異、逐字比對文字。最多同時比 12 份。不用安裝、不用註冊,點開網址把 PDF 拖進去就能用。

**檔案不會上傳。** 所有處理都在你自己的瀏覽器裡完成,PDF 只讀進記憶體,關掉分頁就消失。這個工具不使用 cookie、localStorage 或任何儲存,也不對外發送任何資料。要驗證:按 F12 打開開發人員工具的「網路」分頁,載入 PDF,看看有沒有任何請求送出。

## 功能

- **網格檢視**:多份 PDF 並排,同步捲動。排版可選「自動鋪滿」、固定 2～6 欄,或用齒輪自訂欄 × 列(例如 2×2、3×3)。
- **疊圖檢視**:以一份為基準,其餘各自疊上去,只留下不同的地方,並算出差異百分比。核心運算以 WebAssembly 執行。
- **文字差異**:抽出當頁文字逐字比對,標出增刪。
- **縮放**:可直接輸入百分比,或用 + / −、「符合寬度」。
- **截圖**:把目前畫面複製到剪貼簿或存成 PNG。
- **對頁差**:每份可獨立位移,對齊多／少了封面的檔案。

## 使用

打開上方網址即可。或下載本專案,用瀏覽器(Chrome / Edge)開 `index.html`,把 PDF 拖進去。

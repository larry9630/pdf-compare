# 套版比對台 · 多檔 PDF 差異檢查

**👉 直接開啟使用：https://larry9630.github.io/pdf-compare/**

在瀏覽器裡並排比對多份 PDF、疊圖找差異、逐字比對文字，還可以在上面畫記號、加文字，最後合併匯出成一份 PDF。最多同時比 12 份。

不用安裝、不用註冊，點開網址把 PDF 拖進去就能用。

> **檔案不會上傳。** 所有處理都在你自己的瀏覽器裡完成，PDF 只讀進記憶體，關掉分頁就消失。這個工具不使用 cookie、localStorage 或任何儲存，也不對外發送任何資料。
> 要自行驗證：按 F12 打開開發人員工具的「網路」分頁，載入 PDF，看看有沒有任何請求送出。

## 功能

### 檢視與排版

| 功能 | 說明 |
|---|---|
| **網格檢視** | 多份 PDF 並排，捲動任一份其餘同步跟上（垂直、水平都同步） |
| **排版** | 「自動鋪滿」（右邊不留白，除不盡時往下留空）、固定 2～6 欄，或點齒輪自訂欄 × 列（例如 2×2、3×3） |
| **只看（聚焦）** | 載入 2 份以上時，狀態列會出現數字鈕，**可複選**：點 `02`、`05`、`07` 就只看那三份，版面自動放大。再點一次移出，按「全部」或 `Esc` 還原 |
| **單份放大** | 每格標題列的 `⤢`：只看這一份，再按一次還原 |
| **縮放** | 直接輸入百分比，或用 `＋` / `－`、`⇔`（符合寬度） |
| **平移** | 按住**右鍵**拖曳可移動畫面（標記模式下也能用）；關閉標記時左鍵也可拖曳 |
| **對頁差** | 每份可獨立位移，對齊多／少了封面的檔案 |
| **基準檔** | 點格子左上角的編號即可指定，框線與數字鈕底線會標成洋紅色 |

### 找差異

- **疊圖檢視** — 以一份為基準，其餘各自疊上去，只留下不同的地方：
  - 灰色 = 兩份都有　洋紅 = 只在基準　青色 = 只在對照
  - 每格顯示差異像素百分比，完全相同會直接標「相同」
  - 核心運算以 **WebAssembly** 執行，速度快且精度與原版逐位元組一致
  - 左右方向鍵 / PageUp / PageDown 翻頁
- **文字差異** — 抽出當頁文字逐字比對，刪除標紅刪除線、新增標青底，中英文都能斷詞。掃描檔沒有文字層，請改用疊圖。

### 標記與塗鴉

工具列「標記」一排，按用途分成四群（中間有分隔線），選好工具後在頁面上拖曳即可：

| 群組 | 工具 | 說明 |
|---|---|---|
| 模式 | **關** | 關閉標記，恢復左鍵拖曳平移 |
| 手繪 | **筆 / 螢** | 自由畫筆。按鈕顯示目前模式，**已選中時再按一次即可在「一般筆 ⇄ 螢光筆」之間切換**。螢光筆為半透明，蓋在文字上仍看得到底下的字 |
| 形狀 | **框** | 拖出方框，圈出差異區域 |
| | **箭** | 拖出箭頭，箭頭自動朝向終點 |
| | **◯**（符號） | 圈圈、打勾、叉叉、星號、驚嘆號、問號、三角警示、實心點。點一下放預設大小，拖曳可決定大小。<br>按鈕會顯示目前的符號，**已選中時再按一次即可換符號** |
| 文字 | **字** | 文字方塊。在頁面上點一下，游標就出現在那裡，**直接就地打字**，`Enter` 可換行。點別處或按 `Ctrl`+`Enter` 完成，`Esc` 取消。<br>**點既有的文字即可重新編輯**內容 |

**選取與編輯**：對著已畫好的標記**按右鍵**即可選中，接著用左鍵拖曳移動、拉右下角縮放（按住 Shift 等比）、跨頁搬移、`Delete` 刪除。取消選取後會自動回到原本使用的工具。右鍵點在空白處則是平移畫面。

其他：

- **顏色** — 8 個常用色，另有系統色票可挑任何顏色，也能直接輸入色碼（如 `#1E9EC9`，支援 `#0af` 縮寫）
- **粗細** — 滑桿調整，**每個工具各自記住自己的粗細**（例如螢光筆設粗、一般筆設細，互不干擾）
- **右鍵智慧切換** — 右鍵點在圖形上會自動選取它（並暫時切到選取工具，取消後自動切回原本的筆）；點在空白處則是平移畫面
- **上一步 / 下一步** — `↶` `↷`，或 `Ctrl+Z` / `Ctrl+Y`
- **歷程** — `☰` 打開完整操作清單，顯示每一筆用了什麼工具、畫在哪一份的第幾頁，**點任一列就跳到那一步**，一次退回多步只要一下

標記是以「頁面相對座標」儲存的，因此縮放、切換排版、捲出畫面再捲回來，位置都不會跑掉。

### 輸出

工具列「輸出 ▾」收納三個動作：

- **截圖** — 把目前畫面「複製截圖」到剪貼簿或「存成 PNG」。維持你的欄列排版，每格上方加檔名與頁碼（基準檔為洋紅色底），2 倍解析度；疊圖模式會一併標上差異百分比。標記會一起進截圖，選取框不會。
- **匯出 PDF** — 把載入的**所有文件依序合併成一份 PDF**，每頁的標記以**向量**燒錄進去。原始頁面直接複製，文字與圖表保持原樣不會被光柵化，放大依然銳利。

### 清除

工具列「清除 ▾」分成兩個選項，各自有確認，不會誤按：

- **清除標記** — 只刪畫筆、符號、文字等，**PDF 檔案留著**繼續比對
- **清除檔案** — 移除所有 PDF 回到空白畫面，標記也會一起消失

## 鍵盤快捷鍵

| 按鍵 | 作用 |
|---|---|
| `Ctrl` + `Z` | 上一步 |
| `Ctrl` + `Y`（或 `Ctrl`+`Shift`+`Z`） | 下一步 |
| `Delete` / `Backspace` | 刪除選取中的標記 |
| `Esc` | 取消選取；沒有選取時則回到「全部顯示」 |
| `←` `→` `PageUp` `PageDown` | 疊圖模式翻頁 |

## 使用方式

打開上方網址，把 PDF 拖進畫面即可（也可以點空白畫面上的「點這裡選擇檔案」）。

或下載本專案，用瀏覽器（Chrome / Edge）開 `index.html`。所有元件都在本機，拔掉網路也能跑。

## 已知限制

- **匯出 PDF 的中文會變成底線** — PDF 標準字型只含 ASCII，要輸出中文需嵌入中文字型（會讓檔案多出好幾 MB）。**螢幕顯示與截圖都正常**，只有匯出 PDF 這條路會這樣。
- **最多 12 份** — 再多會吃掉太多記憶體。實務上單檔 50MB 以內、合計 300MB 以內都很順。
- **掃描檔沒有文字差異** — 沒有文字層，請改用疊圖比對。
- **加密／有密碼的 PDF 打不開**。
- 標記與 PDF 一樣**關掉分頁就消失**，不會存檔。要留存請用截圖或匯出 PDF。

## 版本

工具列標題「套版比對台」旁邊有版本標記（例如 `v14`），更新後可用它確認瀏覽器是否已載入新版。
若更新後看起來沒變，多半是瀏覽器快取 —— 按 `Ctrl` + `Shift` + `R` 強制重新整理。
